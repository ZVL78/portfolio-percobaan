# portfolio-percobaan

Portfolio practice website built with HTML and CSS for learning and experimenting.

## Project description
This project is a simple personal portfolio page created as a learning exercise. It focuses on HTML and CSS fundamentals and can be expanded later with more features and better design.

## How to view locally
1. Open `index.html` in a browser.
2. Make sure the image files are placed in the `img/` folder with the same names used in the HTML.

## Required images
Place the following files in the `img/` folder:
- `Nouval.jpg`
- `companion1.jpg`
